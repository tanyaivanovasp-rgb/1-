# Эмулятор командной строки (Shell Emulator)

Данный проект представляет собой графический эмулятор для языка оболочки ОС, имитирующий работу в командной строке UNIX-подобной операционной системы.

## Выполненные этапы и функциональность:
- **Этап 1 (REPL):** Реализован графический интерфейс (GUI) на базе Tkinter, встроен парсер аргументов в кавычках (`shlex`), обрабатываются ошибки неизвестных команд.
- **Этап 2 (Конфигурация):** Поддерживается запуск из CLI с параметрами путей к VFS и стартовому скрипту эмуляции. Реализован построчный вывод команд скрипта с поддержкой комментариев.
- **Этап 3 (VFS):** Виртуальная файловая система разворачивается in-memory (в памяти) на основе физической директории без модификации файлов на реальном диске.
- **Этап 4 (Основные команды):** Реализована полноценная логика системных утилит: `ls`, `cd`, `cat`, `find`, `clear`.
- **Этап 5 (Дополнительные команды):** Добавлена поддержка команды изменения прав доступа `chmod` внутри памяти VFS.

## Инструкция по запуску:
Для тестирования эмулятора в интерактивном режиме запустите главный файл, передав путь к папке VFS и тестовому скрипту:
```bash
python emulator.py ./my_vfs ./start.txt
```
